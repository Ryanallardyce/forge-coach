# Forge Coach — personal Android workout coach

This repository is the home for Forge Coach, a native Android app for three guided gym sessions (Monday, Wednesday, Friday) and two runs (Tuesday, Saturday), beginning 9 November 2026.

## Project status
- GitHub repository connection confirmed on 10 November 2026.
- Source archive is prepared separately in ChatGPT; the Android source has **not yet been uploaded** to this repository.
- A signed or debug APK has **not yet been built or tested**.
- Planned features include spoken work/rest cues, lock-screen workout controls, Bluetooth headphones, offline workout history, and a remote monthly-plan feed.

## Security and privacy
This is a public repository: keep real training records, personal measurements, signing keys, passwords and tokens **out** of commits. Monthly training plans contain generic exercise prescriptions only.

## Training schedule
Monday: Gym A · Tuesday: easy run · Wednesday: Gym B · Thursday: recovery · Friday: Gym C (lighter lower-body training) · Saturday: long run · Sunday: rest.
